Privacy Policy

Last updated: 11 October 2026

Who uses this tool

The Personal Gmail Tool is used only by its owner, for her own Gmail accounts. It has no other users.

What data it accesses

With the owner's permission, the tool uses the Gmail API to read messages, labels and threads, create drafts, and change labels (for example, archive or mark as read). It cannot send, forward or delete mail.

How the data is used and stored

  • Mail content is used only to show the owner her own mail and help her organise it.
  • Sign-in tokens are kept only on the owner's own computer. There is no server and no database.
  • The owner may use an AI assistant on her computer to summarise her own mail or draft replies.
  • Data is not sold, shared with advertisers, or used for any other purpose.

Google API Services User Data Policy

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account › Third-party connections.
